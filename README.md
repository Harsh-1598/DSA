# Data Structures and Algorithms

This repository contains C++ practice programs and solutions for data structures and algorithms.

## Repository Contents

### Basics

This folder covers C++ fundamentals, input and output, conditions, loops, arrays, vectors, strings, functions, patterns, recursion, hashing, linked lists, and the Standard Template Library.

### LeetCode Questions

This folder contains solutions to LeetCode problems. Each problem has its own folder named with the problem number and title. The folder usually contains the original problem statement in README.md and the C++ solution in solution.cpp.

### LeetCode Vs Code

This folder contains LeetCode solutions written as individual C++ files for practice in Visual Studio Code.

### All algorithms.cpp

This file contains selected algorithm implementations in one place.

## Purpose

The repository is used to learn, practice, and organize solutions for common programming concepts and coding problems. New topics and solutions are added as learning progresses.
